# Course bundle test data

Use `course-import-15-courses-150-lessons.xlsx` from the **Courses > Import** action while signed in as an administrator.

The workbook contains:

- 15 published courses
- 1 section per course
- 10 lessons per course (150 lessons total)
- Each course contains 4 video, 3 text, and 3 document lessons

Expected import result: **180 successful records**. Re-importing updates records with the same course, section, and lesson names.
